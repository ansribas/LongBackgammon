# Long Backgammon Assets

This document describes the origin, creation process, and licensing for all multimedia assets (audio and graphics) included in Long Backgammon.

## Audio Assets (`data/sounds/*.wav`)

All sound effects used in the game:
* `checkermove.wav` — Checker sliding sound
* `defeat01.wav`, `defeat02.wav` — Match defeat sound effects
* `diceroll01.wav`, `diceroll02.wav`, `diceroll03.wav` — Dice rolling sounds
* `fireworks.wav` — Victory celebration fireworks audio
* `newgame.wav` — New game start sound
* `paneldock.wav` — Docking sound for side panels
* `placement_step.wav` — Individual checker placement sound
* `score_deduct.wav`, `score_ding.wav` — Match tally increment / decrement chimes
* `star_pop.wav` — Flying score star pop sound
* `table_reveal.wav` — Game Over table reveal chime
* `tally_tick.wav` — Tally count tick
* `victory.wav` — Victory fanfare

* **Origin / Generator:** Generated using ElevenLabs AI Sound Effects generator ([elevenlabs.io](https://elevenlabs.io)).
* **Post-processing:** Trimmed, normalized, edited, and converted to uncompressed 16-bit 48 kHz stereo WAV by Aleksey Svetlov.
* **License:** [Creative Commons CC0 1.0 Universal (CC0-1.0) / Public Domain Dedication](https://creativecommons.org/publicdomain/zero/1.0/).

## Graphical Assets (`data/images/*.png`)

All board themes and checker textures:
* `marble_board.png` — Green marble backgammon board texture
* `marble_white.png`, `marble_black.png` — Marble checkers
* `marble_dicecursor.png` — Drag cursor for marble theme
* `wood_board.png` — Classic wood backgammon board texture
* `wood_white.png`, `wood_black.png` — Wooden checkers
* `wood_dicecursor.png` — Drag cursor for wood theme

* **Origin / Generator:** Generated using OpenAI ChatGPT / DALL-E image generation via OpenAI Media Service API (as reflected in standard C2PA provenance metadata).
* **Post-processing:** Cropped, color-balanced, texture-aligned, and transparent-masked by Aleksey Svetlov.
* **License:** [Creative Commons CC0 1.0 Universal (CC0-1.0) / Public Domain Dedication](https://creativecommons.org/publicdomain/zero/1.0/). In accordance with US Copyright Office policy and Fedora Project AI Guidelines, AI-generated synthetic media without human authorship is not subject to copyright.
